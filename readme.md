# 📊 Data Analyzer & Transformer

A simple Python CLI project for analyzing, filtering, sorting, and transforming numerical data.
🎥 Video Explanation

▶️ Watch the Project Explanation

Replace YOUR_VIDEO_LINK_HERE with your YouTube or video link.

✨ Features

📝 Input numerical dataset
📊 Display minimum, maximum, total, and average
🧮 Calculate factorial using recursion
🔍 Filter data using lambda and filter()
↕️ Sort data in ascending/descending order
📈 Display dataset statistics
🔄 Menu-driven CLI interface

🧠 Concepts Used

Concept Usage
Lists Store dataset
Functions Organize program
Loops Process data
Recursion Factorial
Lambda Filter values
filter() Data filtering
.sort() Data sorting
match-case Menu system
Multiple Return Statistics

🖥️ Menu

1. Input Data
2. Display Data Summary
3. Calculate Factorial
4. Filter Data by Threshold
5. Sort Data
6. Display Dataset Statistics
7. Exit Program

🚀 How to Run

1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project

3. Run the program
